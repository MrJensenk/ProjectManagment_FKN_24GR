| Папка | Фаза | Содержание |
|-------|------|------------|
| `phase-1/` | Фаза 1. Выбор концепции проекта | концепции и критерии, экспертные оценки, нечёткий коллективный TOPSIS, чёткий коллективный МАИ, выводы |

| `phase-5/` | Фаза 5. Планирование | задачи, ресурсы, предшествование, эвристики упорядочения, календарный план |
